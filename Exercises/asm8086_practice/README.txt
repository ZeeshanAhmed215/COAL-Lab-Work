8086 Assembly Practice Programs (Q1-Q25)
Written in MASM/TASM-style syntax with DOS INT 21h; works in EMU8086, DOSBox + MASM/TASM.
Run (MASM):  masm Q01_display_message.asm;  link Q01_display_message.obj;  Q01_display_message.exe
Run (TASM):  tasm file.asm  /  tlink file.obj  /  file.exe
In EMU8086 just open the .asm file and press Emulate / Run.
Edit the values in the .DATA section (or the MOV lines) to test other inputs.
